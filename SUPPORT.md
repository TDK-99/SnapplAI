# Getting Help with SnapplAI

If you need help, here's where to go depending on what you need.

## I have a question about how something works

Open a thread in [Discussions (Q&A)](https://github.com/TDK-99/SnapplAI/discussions/categories/q-a). Someone from the community or the maintainer will get back to you.

## I found a bug or something isn't working

Open an [Issue](https://github.com/TDK-99/SnapplAI/issues) with:

- What you expected to happen
- What actually happened
- Steps to reproduce it
- Your Python version and OS

## I have an idea or want to propose a change

Start a thread in [Discussions (Ideas)](https://github.com/TDK-99/SnapplAI/discussions/categories/ideas). If the idea gets traction, it becomes an Issue, then a PR. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full flow.

## Setup problems

Make sure you're running Python 3.12 and have followed the setup steps in [CONTRIBUTING.md](CONTRIBUTING.md). If you're still stuck, open a Q&A thread in Discussions with the error output.
